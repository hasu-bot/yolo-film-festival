# あなたのまちの映画祭 — Your Town Film Festival

熊本のクリエイティブコミュニティ **YOLO** が主催する短編映画祭の公式サイト。
会場は熊本・電気館（Denkikan）。テーマは「地元」で、九州の作り手による短編映画を上映します。

**デザイン方針: 「上映前の、あの一瞬」＝暖色の光・感動トーン。** ヒーローは写真を使わず
**暖色のグラデーションの光＋明朝・小さめ・余白**の中央タイトルカード。以降のセクションは
左フィルムレール／ニュースティッカー／コンセプト／プログラム横スクロール／4つの特徴／
生成り紙の応募CTA／フッターという構成を、ヒーローと同じ暖色トーンで統一しています。
詳細な意図は `docs/DESIGN_BRIEF.md` を参照。**Phase-1 のトップページ**を実装済み。

## 構成

```
index.html        トップページ（インラインstyleなし）
css/
  tokens.css      デザイントークン（配色・タイポ・流体スケール・余白）＋リセット＋共通プリミティブ
  components.css  再利用コンポーネント一式（ヘッダー/ボタン/ヒーロー見開き/ニュース/
                  各セクション/フィルムカード/アニメーション/レスポンシブ）
js/
  site.js         共通挙動（ヘッダーのスクロール状態 / スクロールリビール /
                  モバイルナビ / プログラム横スクロール）
assets/           プレースホルダー画像（※すべて差し替え前提）
```

CSS はトップ専用ではなく、**ページ2以降（About / Program / Schedule / Access / News /
Archive など）での使い回しを前提**に `tokens.css` と `components.css` に分解しています。
配色・タイポ・余白は CSS 変数なので、トークンを書き換えるだけで全ページのトーンを一括変更できます。

## セクション

1. **ヒーロー** — 左に大きな見出し（明朝・流体）＋メタ情報、右に全面写真の“見開き”
2. **News** — 最新ニュースの横一列ストリップ（誌面風・静的）
3. **01 Concept** — 大きな写真＋特大の見出しのエディトリアル・スプレッド
4. **02 Program** — ダックな全面バンドで作品を大きく見せる横スクロール
5. **03 Features** — 大きな番号付きインデックスリスト（罫線区切り）
6. **Submit** — 朱赤の全面ブロックで締める応募CTA
7. **Footer** — ダークなフッター（SNS動線つき）

## 差し替え前提・仮の要素（公開前に対応）

- **写真**: `assets/*.jpg` はすべてプレースホルダー。パスは固定のままなので、ソース画像を
  差し替えるだけで反映されます。
- **監督名**: 確定前のため一覧カードはすべて仮テキスト **「監督名（仮）」** で表示。
- **作品情報・日程・チケット情報・応募要項**: ダミーコピー（多くが「近日発表」）。
- **`<title>` / meta / OGP**: 枠を用意済み。`og:url` と `og:image`（1200×630）は
  `https://example.com/...` の仮値なので本番値・実画像へ差し替えてください。
- **ナビ/フッターのリンク**: 他ページ未実装のため多くが `#`（ダミー）。
- **ロゴ**: 専用ロゴ未作成。現状は組み文字（Shippori Mincho B1）。favicon は簡易のSVG。

## アクセシビリティ / モーション

- スクロールリビールと Ken Burns は `@media (prefers-reduced-motion: no-preference)` の内側。
  「動きを減らす」設定では停止し、コンテンツは静止状態で全可視。JS 側にも reduced-motion /
  IntersectionObserver 非対応時のフェイルセーフあり。
- キーボード操作用の `:focus-visible` リング、画像の意味のある `alt`、`loading="lazy"` を付与。
