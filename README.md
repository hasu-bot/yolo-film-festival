# あなたのまちの映画祭 — Your Town Film Festival

熊本のクリエイティブコミュニティ **YOLO** が主催する短編映画祭の公式サイト。
会場は熊本・電気館（Denkikan）。テーマは「地元」で、九州の作り手による短編映画を上映します。

ダーク・シネマ調（暖色のブラウンブラック＋朱赤＋ゴールド、フィルムグレイン）の
モーションリッチなサイト。**Phase-1 のトップページ**を実装済みです。

## 構成

```
index.html        トップページ（インラインstyleなし）
css/
  tokens.css      デザイントークン（配色・タイポ・余白・角丸・影・モーション）＋リセット＋.grain
  components.css  再利用コンポーネント一式（レール/ヘッダー/ボタン/カード/バッジ/
                  ティッカー/各セクション/アニメーション/レスポンシブ）
js/
  site.js         共通挙動（ヘッダーのスクロール状態 / スクロールリビール /
                  モバイルナビ / プログラム横スクロール）
assets/           プレースホルダー画像（※すべて差し替え前提）
```

CSS はトップページ専用ではなく、**ページ2以降（About / Program / Schedule / Access /
News / Archive など）での使い回しを前提**に `tokens.css` と `components.css` に分解しています。

## 確認方法

静的サイトなので、ファイルを直接開くか簡易サーバーで配信するだけで確認できます。

```bash
npx http-server . -p 8080   # → http://localhost:8080
```

最終的な配信形態は **スタンドアロンの静的HTML → WordPress（SWELLテーマ / Xserver）へ埋め込み**を想定。

## 差し替え前提・仮の要素（公開前に対応）

- **写真**: `assets/*.jpg` はすべてプレースホルダー。CSS の `filter`（セピア/モノトーン）で
  ムードを付けているため、ソース画像を差し替えるだけで雰囲気は維持されます。
  - ヒーロー背景は写真を使わず CSS で構築（グラデーション＋投影グロー＋グレイン）。
- **監督名**: 確定前のため一覧カードはすべて仮テキスト **「監督名（仮）」** で表示。
- **作品情報・日程・チケット情報・応募要項**: ダミーコピー。
- **`<title>` / meta / OGP**: 枠を用意済み。`og:url` と `og:image`（1200×630）は
  `https://example.com/...` の仮値なので本番値・実画像へ差し替えてください。
- **ロゴ**: 専用ロゴ未作成。現状は組み文字（Shippori Mincho B1）。

## モーションとアクセシビリティ

Ken Burns・ニュースティッカー・レール滴下・ヒーロー登場・スクロールリビール・
投影フリッカーは、すべて `@media (prefers-reduced-motion: no-preference)` の内側に置いています。
**「動きを減らす」設定の利用者にはアニメーションが停止し**、各要素は静止した完成状態
（ズームなし／静的なライン／全コンテンツ可視）で表示されます。スクロールリビールは
JS 側でも reduced-motion / IntersectionObserver 非対応時はコンテンツを常時可視にする
フェイルセーフを実装しています。
