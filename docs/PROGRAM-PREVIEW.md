# 作品決定後の表示プレビュー（本番反映禁止）

このブランチは、架空の6作品を使って掲載後の見え方を確認する専用プレビューです。
実際の応募作品・個人情報・選考結果は含みません。mainへのマージや本番デプロイは行いません。

- `program.html`: 作品写真枠、作品名、部門、尺、監督名、紹介文、上映時間へのリンク
- `schedule.html`: 各ブロックに個別作品と仮の開始時刻を表示し、作品紹介へ相互リンク
- 写真枠はプレースホルダー。実際の作品写真を無関係な画像で代用しない
- 共通データは `content/program-preview.json`。6作品の純上映時間は95分、転換を含めて105分
- `node scripts/build-program-preview.mjs` で2ページを再生成する。元テンプレートのGit SHAはスクリプトに固定
- 検索インデックス禁止、分析タグなし。VercelのPreview環境のみで確認する

本番用に採用する際は、確定作品と掲載許可済み写真に差し替え、上映順・尺・転換時間を確定し、
サンプル表示とプレビュー専用設定を整理した別PRで公開判断を行う。
