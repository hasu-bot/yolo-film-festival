## 原稿・利用範囲

- 現行の公開プログラムの上映順、監督名、尺、上映7作品・入選4作品の区別を維持。
- あらすじと「まちとのつながり」は応募データの原文。改行コードだけHTML用に変換。
- 応募データの `rights_confirmed` と `screening_consent` は対象11作品とも true を確認。
- 審査用の本編URL、パスワード、個人連絡先、審査結果の内部資料は含めない。
- 予告編リンクは応募データの予告編欄に記載されたYouTube URLのみ。
- 外部画像を直接埋め込まず、応募者提供素材と前回確認済みサムネイルのWebPをサイト内に保存。画面全体を維持し、ポスターの文字やスチールを切り抜かない。
- 画像の原本と取得元の記録は作業フォルダに保持。個別の素材共有URLは公開リポジトリへ記載しない。
