# あなたのまちの映画祭 完全設計書

> 「あなたのまちの映画祭」を今後何年も続けるための運営設計。
> 上位計画：Creative YOLO マスタープラン／長期ロードマップ（yolo-members リポジトリ `docs/creative-yolo/`）。
> サイトのデザイン意図は既存の `docs/DESIGN_BRIEF.md` を正とする。

---

## 1. 位置づけと目的

- Creative YOLO の**年次の舞台（映像の柱）**。テーマは「あなたのまち」、会場は熊本・電気館
- 目的の優先順位：①九州の作り手の発表機会 ②市民と映画の接点 ③YOLOへの入口 ④収益（4番目でよい）
- 成否の第一指標は**応募リピート率**（前年応募者が翌年も出すか）。動員は第二指標

## 2. 部門設計

| 部門 | 内容 | ねらい |
|---|---|---|
| 実写部門 | テーマ「あなたのまち」の短編（目安 5〜25分） | 本流。九州の作り手の受け皿 |
| AI部門 | 本編映像の**半分以上を生成AIでつくった**短編（目安 5〜25分） | 新規参入層の開拓。「機材がなくても作れる」入口 |

- AI部門は**手段の部門であってジャンルではない**。審査基準は実写と同じ「物語とまちらしさ」

### 部門の判定基準（応募者が自分で判断できる形にする）

「AIを主要な工程に使ったか」という主観的な線引きはしない。**画がどこから来たか**の一点で決める。

- **本編尺のうち、AIが生成した映像が占める割合が 50%以上 → AI部門**
- **50%未満 → 実写部門**
- 脚本づくり・音楽・音声合成・色調整・ノイズ除去などにAIを使っていても、
  **映っている画がカメラ由来なら実写部門**
- 半々でどちらとも言える場合は**応募者が選ぶ**（選んだ部門で審査。後からの変更は不可）
- 事務局の一次チェックで明らかな不一致（AI生成9割なのに実写部門など）が見つかった場合は
  **部門の移動を提案する。部門違いを理由に落とさない**

**AI利用の申告は両部門とも必須。**実写部門でもAIの使用有無・ツール・工程を申告してもらう
（申告をAI部門だけにすると、実写部門に紛れたAI素材の権利リスクを拾えない → §5）

## 3. 応募設計（最優先の整備対象）

**entry.html は作成済み**（2026-07-04・募集概要／実写・AI部門／応募4ステップ／要件チェック／上映許諾要約／FAQ／CTA）。
残るは応募フォームの実装のみ。**`yolo-tickets`（ラストコールの予約システム）に応募モジュールを追加する方針**（設計は `docs/ENTRY-FORM-SPEC.md` §0）。公開後、entry.html の応募ボタンの href を1箇所差し替える（それまではメール応募として機能）。

### 応募フロー
```
entry.html（応募要項）→ 応募フォーム（yolo-tickets。チケット予約と同一基盤）
→ 自動受付メール → 事務局で形式チェック（1週間以内）→ 受付番号通知
```

### 応募要項（テンプレ）
- 資格：**地域を問わない**（2026-07-26 変更。第2回は母数確保を優先し、九州縛りを外した）。九州ゆかりの作品は「歓迎」と示すが応募条件にはしない
- 尺：5〜25分（本編。予告・クレジット含む）
- 完成時期：**制限なし**（2026-07-26 変更。既発表作品も可。ただし過去回で上映した作品は不可）。新作サイクルを作る狙いは第3回以降で再検討する
- 提出物：本編データ（限定公開URL可）／スチール2枚以上／あらすじ200字／監督プロフィール／AI利用申告（AI部門）
- 応募料：**2027年まで無料**。2028年から1作品1,000円目安（無料枠＝学生は継続）

## 4. 審査設計

### 体制（3層で「身内感」を排除する）
1. **一次（事務局）**：形式要件・権利チェックのみ。内容で落とさない
2. **本審査**：主催者と映像に関わる方々で行う。外部審査員を過半数にするのが理想だが、
   **第2回は招聘できるか未確定**（2026-07-26 時点）。確定するまでサイトに人数・名前を書かない
3. **観客賞**：当日投票（紙 or QR）。「まちの映画祭」の性格上、必ず残す

### 審査基準（公開する）
| 基準 | 配点 |
|---|---|
| 物語（心が動くか） | 40 |
| まちらしさ（テーマ「あなたのまち」との響き合い） | 30 |
| 技術・表現（部門特性を考慮） | 30 |

- 結果は応募者全員にメールで通知する
- **講評の全員返送は第2回では行わない**（2026-07-26 判断）。運営体制に対して重すぎるため。
  リピート率＝第一指標への効きは大きいので、体制が整う回で復活させたい。
  代替として、上映されなかった作品にも「入選」としてサイト・パンフに名前を残す枠を設ける

### 賞
- グランプリ／部門賞（実写・AI）／観客賞／（2027〜）スポンサー冠賞
- 副賞は賞金より「次につながるもの」：次回作の相談サイト優先マッチング、電気館での単独上映権など

## 5. 権利・コンプライアンス

- 上映権：応募規約で「本映画祭および公式アーカイブでの上映・部分引用（予告等）」の許諾を得る。**それ以外の権利は作り手に残す**
- 音楽・肖像・ロケ地：応募者の権利処理誓約＋一次チェックで確認
- AI部門：学習元・生成物の権利状況の申告欄を設け、係争リスクのある作品は受付段階で相談対応
- 未成年応募：保護者同意書

## 6. 収益・費用設計

### 費用（想定・第2回規模）
| 項目 | 目安 |
|---|---|
| 会場費（電気館1日） | 10〜20万円 |
| 審査員謝礼（3名） | 3〜6万円 |
| 印刷・デザイン・雑費 | 5万円 |
| 予備 | 3万円 |
| **計** | **約25〜35万円** |

### 収入源（優先順）
1. **チケット**：一般 1,500円／学生 800円 目安。来場150人 ≒ 18万円
2. **スポンサー**（2027年から本格化。§7）
3. **応募料**（2028年から）
4. 物販・パンフ（当面は宣伝物と割り切る）

**原則：単年黒字を狙わず「3年目までに収支トントン、4年目から次年度繰越が出る」設計。**

## 7. スポンサー設計（2027〜）

| プラン | 金額目安 | 提供 |
|---|---|---|
| パートナー | 10万円 | ロゴ掲載（サイト・パンフ・スクリーン）＋招待券 |
| 部門スポンサー | 20万円 | 上記＋冠賞（「◯◯賞」）＋授賞式登壇 |
| メイン | 50万円 | 上記＋「presented by」表記＋MAGAZINE タイアップ記事 |

- 営業先の優先順：①電気館周辺・新市街の商店 ②熊本のクリエイティブ関連企業（機材・印刷・広告）③金融機関・自治体系の助成
- **助成金**（文化庁・県市の文化振興・商店街活性化系）は毎年1〜2本申請を SOP 化。締切カレンダーを 12月に確認
